# TP3 - Projet Individuel : Analyse d'une transaction Bitcoin TestNet4

## 1. Sujet choisi
Étude et explication d'une transaction réelle sur le réseau Bitcoin TestNet4, avec un focus particulier sur la consommation des UTXO (Unspent Transaction Outputs) et le calcul des frais de transaction.

# 2. Démarche
1. Connexion à un explorateur de blocs public pour le réseau Bitcoin TestNet4.
2. Sélection et observation d'une transaction validée récente.
3. Décomposition des données brutes de la transaction pour identifier :
   - L'adresse de l'expéditeur via les entrées (Inputs).
   - L'adresse du destinataire et le montant reversé via les sorties (Outputs).
   - La commission versée aux mineurs (Frais).

## 3. Résultat obtenu
- Compréhension pratique du modèle UTXO de Bitcoin (chaque transaction consomme des sorties non dépensées précédentes et en crée de nouvelles).
- Calcul précis de la différence entre les entrées et les sorties confirmant le coût de la transaction en satoshis.

## 4. Outils utilisés
- GitHub et GitHub Desktop pour le versionnage et les commits.
- VS Code pour la rédaction des fichiers Markdown.
- Explorateur de blocs TestNet4.
- Assistant IA pour la structuration et la formulation du rapport.
